# 맘마두리 공개 웹 구성

작성: 2026-10-05

## 결정
- 기존 TwinLabs 정적 HTML 호스팅을 유지하고 `/mammaduri/`에 소개·지원·개인정보 페이지를 배치한다.
- 앱에서 선택한 웃는 밥그릇 아이콘, 살구색·아이보리와 짙은 갈색을 사용한다. 외부 폰트·분석 SDK는 추가하지 않는다.
- 핵심 가치는 식단 계획 → 아이별 식사 기록 → 가족 공유다. 가상 데이터 화면은 예시임을 표시한다.
- 확인된 스토어 주소가 없으므로 ‘출시 준비 중’으로 안내한다. 다운로드 버튼이나 출시일을 꾸며내지 않는다.
- 운영자 표기는 사용자가 확인한 `TwinLabs / 맘마두리 개인정보 담당자`, 이메일은 `hello@twinlabs.studio`다.
- 정책은 시행 전 검토본으로 제공한다. 문의 보유기간, 위탁·국외 이전 고지 및 아동 정보 처리 절차 확정 후 공개한다. 세 페이지는 준비 단계에서 noindex로 둔다.

## 이유
Debt Freedom의 소개·지원·정책 구조는 재사용할 수 있지만, 맘마두리는 로그인·가족 공유가 있으므로 데이터 설명은 새로 작성해야 한다. 별도 빌드 의존성 없이 유지할 수 있는 정적 페이지가 현재 규모에 적합하다.

## 2026-11-12 출시 후 검색 공개

소개·지원 페이지는 검색 색인을 허용하고 canonical과 공유 메타데이터를 제공한다. 최초 준비 단계의 noindex 결정을 이 두 페이지에 한해 대체한다. 개인정보 방침은 기존 noindex를 유지하며 접근은 허용한다. robots.txt는 다른 앱의 기존 수집 범위를 막지 않는다. 사이트맵에는 루트·맘마두리 소개·지원의 대표 URL만 포함한다.

출시 기능을 일반 HTML 텍스트와 FAQ로 설명한다. WebPage/ContactPage 및 소개 대상 MobileApplication 정보를 표시하며 검증하지 않은 평점·리뷰를 추가하지 않는다. 구조화 데이터나 AI 전용 파일로 검색 노출을 보장하지 않는다.
