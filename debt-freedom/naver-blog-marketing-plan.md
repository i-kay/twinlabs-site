# Debt Freedom 네이버 블로그 마케팅 실행안

## 1. 목표

네이버 블로그에서 부채 상환 관련 정보를 찾는 잠재 사용자를 확보하고, Debt Freedom 앱 설치 및 첫 상환 시뮬레이션 완료를 유도한다.

Debt Freedom의 핵심 가치 제안은 다음과 같다.

- 월 추가 상환액에 따른 완납 예상일 계산
- 여러 부채의 상환 전략 시뮬레이션
- 금융기관 및 마이데이터 연결 없이 이용
- 사용자가 입력한 부채 정보를 기기에만 저장
- 로그인 없이 이용 가능

운영 원칙은 정보성 콘텐츠 80%, 앱 소개 콘텐츠 20%로 설정한다. 단순한 앱 홍보 채널이 아니라 부채 상환 질문에 실용적인 답을 제공하는 전문 채널로 포지셔닝한다.

> Debt Freedom은 금융기관 또는 금융자문 서비스가 아니다. 계산 결과는 사용자가 입력한 조건에 따른 참고용 시뮬레이션이다.

## 2. 네이버 계정 및 블로그 개설

### 2.1 계정 구성

개인용 계정과 분리된 TwinLabs 브랜드 전용 네이버 계정을 사용한다.

네이버 ID 후보:

- `twinlabsstudio`
- `debtfreedomkr`
- `debtfreedomapp`

블로그 ID 후보:

- `debtfreedom_kr`
- `debtfreedomlab`
- `debtfree_note`

권장 블로그 정보:

- 블로그명: `빚 없는 날을 계산하는 Debt Freedom`
- 별명: `Debt Freedom`
- 소개글: `대출과 카드빚의 상환 순서, 추가 상환 효과, 완납 예상일을 쉽게 설명합니다. Debt Freedom은 금융기관이 아닌 부채 상환 시뮬레이션 앱입니다.`

네이버 회원가입 후 블로그 홈 또는 네이버 블로그 앱에서 블로그 ID를 생성한다. 네이버 ID 하나당 블로그 하나가 제공되며, 블로그 데이터는 다른 계정으로 이전하거나 양도할 수 없으므로 장기간 관리할 소유자 명의로 개설한다.

참고: [네이버 블로그 개설 안내](https://help.naver.com/service/5593/contents/15183)

### 2.2 계정 관리 기록

운영권 분쟁과 계정 분실을 예방하기 위해 다음 내용을 사내 보안 저장소에 기록한다.

- 계정 명의자
- 복구 전화번호 및 이메일
- 2단계 인증 설정 여부
- 백업 코드 보관 위치
- 블로그 개설일 및 주소
- 운영 책임자
- 프로필과 콘텐츠 원본 보관 위치

비밀번호, 인증 코드, 개인정보는 일반 문서나 Git 저장소에 기록하지 않는다.

계정 개설 과정의 본인 인증과 약관 동의는 실제 계정 소유자가 직접 수행한다.

### 2.3 블로그 초기 설정

권장 카테고리:

1. 빚 갚는 방법
2. 대출 이자 계산
3. 상환 시뮬레이션
4. Debt Freedom 사용법
5. 업데이트 및 공지

프로필과 타이틀은 금융기관으로 오인될 수 있는 디자인보다 계산기, 달력, 완주선을 연상시키는 담백한 디자인을 사용한다.

참고: [네이버 블로그 프로필 설정 안내](https://help.naver.com/service/5593/contents/15208)

## 3. 설치 전환 기반 정비

### 3.1 권장 전환 경로

```text
네이버 검색
→ 정보성 블로그 글
→ 실제 계산 예시
→ 내 조건으로 계산하기 CTA
→ 앱스토어
→ 앱 설치
→ 첫 부채 입력 및 시뮬레이션 완료
```

### 3.2 공식 홈페이지 보완

현재 Debt Freedom 공식 웹페이지에는 앱스토어 설치 링크가 없으므로 블로그 홍보 전에 다음 요소를 추가한다.

- App Store 또는 Google Play 설치 버튼
- 앱 화면 이미지 4~6장
- 지원 OS와 가격
- 개인정보 로컬 저장 설명
- 금융기관의 공식 서비스가 아니라는 안내
- 계산 결과가 참고용이라는 안내
- 스토어별 전환 측정 링크

### 3.3 링크 추적

글마다 서로 다른 UTM 파라미터를 사용한다.

```text
?utm_source=naver
&utm_medium=blog
&utm_campaign=debt_freedom_launch
&utm_content=extra_payment_100k
```

가능하면 AppsFlyer, Adjust 또는 앱스토어 캠페인 링크로 설치까지 측정한다. 설치 추적 도구를 사용하지 못할 경우 최소한 다음 이벤트를 측정한다.

- 블로그에서 랜딩페이지로 이동
- 랜딩페이지의 앱스토어 버튼 클릭
- 스토어별 클릭 수
- 앱 내 첫 시뮬레이션 완료

## 4. 검색 키워드 전략

초기에는 검색량이 거의 없는 브랜드 키워드보다 구체적인 문제와 상황을 나타내는 롱테일 키워드를 공략한다.

### 4.1 핵심 키워드군

- 빚 빨리 갚는 방법
- 대출 여러 개 상환 순서
- 대출 원금 먼저 갚기
- 대출 조기상환 계산
- 매달 10만 원 추가 상환
- 대출 완납 기간 계산
- 고금리 대출 먼저 갚기
- 눈덩이 방식 눈사태 방식
- 카드론 상환 계획
- 학자금대출 상환 계획
- 중도상환수수료 계산
- 대출 갈아타기 전 계산

`Debt Freedom 앱 추천`처럼 브랜드 중심으로 제목을 구성하기보다 사용자가 처한 상황과 궁금증을 제목에 반영한다.

## 5. 첫 4주 콘텐츠 계획

주 3회, 총 12편 발행을 기본 계획으로 삼는다.

| 주차 | 주제 |
|---|---|
| 1주차 | 대출이 여러 개라면 무엇부터 갚아야 할까 |
| 1주차 | 매달 10만 원 추가 상환하면 완납일은 얼마나 당겨질까 |
| 1주차 | Debt Freedom으로 빚 없는 날짜 계산하는 방법 |
| 2주차 | 고금리 우선 상환과 소액 대출 우선 상환 비교 |
| 2주차 | 추가 상환 전 반드시 확인할 중도상환수수료 |
| 2주차 | 카드론과 신용대출을 함께 관리하는 예시 |
| 3주차 | 월 상환 여력이 20만 원 늘었을 때의 변화 |
| 3주차 | 대출 상환 계획표를 세울 때 빠뜨리는 비용 |
| 3주차 | Debt Freedom에 입력한 부채 정보는 어디에 저장될까 |
| 4주차 | 눈사태 방식과 눈덩이 방식 비교 |
| 4주차 | 금리가 1% 달라지면 총이자는 얼마나 달라질까 |
| 4주차 | 한 달 사용 후 상환 계획 점검 체크리스트 |

최소 5개의 기본 콘텐츠를 준비한 다음 블로그를 공개한다. 글 한 편만 등록된 상태에서 외부 홍보를 시작하지 않는다.

## 6. 게시글 작성 템플릿

제목 예시:

> 대출 3개, 어떤 것부터 갚아야 할까? 두 가지 상환 방식 비교

본문 구성:

1. 독자가 처한 상황 또는 질문 제시
2. 계산에 사용할 가상의 대출 조건 공개
3. 상환 방법 A와 B 비교
4. 월 추가 상환액에 따른 결과 비교
5. 각 방식이 적합한 상황 설명
6. 중도상환수수료 등 예외 조건 안내
7. Debt Freedom에서 직접 계산하는 화면 제시
8. 설치 CTA 배치
9. 참고용 계산이라는 고지

권장 CTA:

> 내 대출 금액과 금리를 입력해 빚이 0원이 되는 날짜를 계산해 보세요.

권장 이미지:

- 상환 전후 비교표
- 월별 잔액 그래프
- 앱 사용 화면
- 계산 조건 요약 카드
- 핵심 결론 카드

글 한 편에 자체 제작 이미지 5~8장을 사용하되, 같은 키워드를 부자연스럽게 반복하거나 유사한 문서를 대량 생성하지 않는다.

게시글 등록 시 `전체 공개`와 `검색 허용`을 활성화한다.

참고: [네이버 블로그 검색 노출 설정](https://help.naver.com/service/5593/contents/15555)

## 7. 광고 및 금융 관련 고지

운영사가 직접 앱을 홍보한다는 사실을 글 첫머리에서 밝힌다.

> 이 글은 Debt Freedom 개발사 TwinLabs가 직접 작성한 앱 홍보 콘텐츠입니다.

모든 계산 콘텐츠 하단에는 다음 문구를 넣는다.

> Debt Freedom은 금융기관이나 금융자문 서비스가 아닙니다. 계산 결과는 입력값에 따른 참고용 시뮬레이션이며, 실제 상환액, 이자 및 수수료와 다를 수 있습니다. 대출 계약 조건은 해당 금융기관에서 확인하세요.

### 7.1 사용을 피해야 할 표현

- 반드시 빚을 줄여준다
- 최적의 상환법을 보장한다
- 이 앱만 사용하면 신용점수가 오른다
- 근거 없이 특정 금액의 이자 절감을 보장한다
- 일반 사용자처럼 위장한 자사 후기
- 가상 결과를 실제 이용자의 결과처럼 제시한다

가상 사례에는 제목 또는 본문에서 `예시 조건`, `가상 사례` 등의 표현을 명확하게 표시한다.

## 8. 콘텐츠 배포 확장

블로그 게시글을 그대로 복제하지 않고 채널에 맞게 재가공한다.

- 네이버 클립: `매달 10만 원 더 갚으면 생기는 변화` 형식의 20초 영상
- 이미지형 클립: 상환 전후 비교 카드 4장
- 네이버 지식iN: 질문에 독립적으로 충분한 답변을 제공하고 필요한 경우에만 참고 링크 제공
- 재무 및 절약 관련 블로그와 협업
- 초기 사용자 10~20명의 실제 사용 피드백 수집

클립 프로필은 동일한 브랜드 계정으로 개설한다. 블로그와 클립 프로필의 연결은 해지가 제한될 수 있으므로 계정 소유 관계를 확인한 후 진행한다.

참고: [네이버 클립 프로필 개설 안내](https://help.naver.com/service/30048/contents/24411)

## 9. 성과 측정

### 9.1 초기 30일 목표

- 게시글 12개 이상
- 검색 노출 키워드 30개 이상
- 블로그 방문 대비 랜딩페이지 클릭률 5% 이상
- 랜딩페이지 방문 대비 앱스토어 클릭률 25% 이상
- 앱스토어 방문 대비 설치율 20% 이상
- 설치 대비 첫 시뮬레이션 완료율 40% 이상

목표 수치는 초기 가설이며 실제 데이터가 쌓이면 유입 키워드, 운영체제, 콘텐츠 유형별로 재설정한다.

### 9.2 병목 진단

| 현상 | 우선 점검 항목 |
|---|---|
| 검색 노출이 적음 | 제목, 검색 의도, 키워드 및 콘텐츠 품질 |
| 조회는 있지만 랜딩 클릭이 적음 | CTA, 앱과 콘텐츠의 관련성, CTA 위치 |
| 스토어 클릭은 많지만 설치가 적음 | 앱스토어 설명, 평점, 아이콘, 스크린샷 |
| 설치는 되지만 사용이 적음 | 온보딩, 첫 부채 입력 과정, 초기 가치 전달 |

## 10. 실행 순서

- [ ] 브랜드 소유자의 네이버 계정을 개설한다.
- [ ] 블로그 ID, 블로그명, 별명 및 소개글을 확정한다.
- [ ] 계정 복구 및 운영 정보를 안전한 사내 저장소에 기록한다.
- [ ] 공식 홈페이지에 앱스토어 설치 링크를 추가한다.
- [ ] 앱스토어 상세 페이지의 설명과 스크린샷을 정비한다.
- [ ] 블로그 및 게시글별 전환 측정 링크를 생성한다.
- [ ] 블로그 카테고리와 프로필을 설정한다.
- [ ] 기본 콘텐츠 5편을 제작한다.
- [ ] 블로그를 공개하고 주 3회 발행을 시작한다.
- [ ] 2주차부터 네이버 클립 콘텐츠를 병행한다.
- [ ] 매주 검색 노출, 클릭, 설치 및 첫 시뮬레이션 데이터를 검토한다.
- [ ] 4주 후 성과가 높은 키워드와 콘텐츠 형식에 발행 비중을 집중한다.

## 11. 최우선 과제

블로그 디자인이나 발행량보다 먼저 정상적으로 작동하고 측정 가능한 앱 설치 링크를 준비해야 한다. 전환 측정이 없으면 어떤 검색어와 콘텐츠가 실제 앱 설치로 이어지는지 판단할 수 없다.
