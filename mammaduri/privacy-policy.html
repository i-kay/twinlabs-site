처리 정보저장·공유외부 서비스보유·삭제권리·문의공개 전 확인

1. 어떤 정보를 왜 처리하나요?

맘마두리는 보호자가 아이의 식단을 계획하고 기록하는 앱입니다. 아이의 실명 대신 별명을 사용해 주세요. 주민등록번호, 연락처, 민감한 건강정보를 메뉴나 별명에 입력하지 마세요.

구분 정보와 목적
식단·식사 기록 아이 별명과 내부 식별자, 날짜·끼니·메뉴·대상 아이, 먹은 정도·반응. 계획과 이력 확인에 사용합니다.
로그인 로그인 제공자와 계정 식별자, Firebase 사용자 식별자. 제공자가 전달하는 범위에서 이메일·프로필 정보가 인증 계정에 포함될 수 있습니다. 회원 식별과 로그인 유지에 사용합니다.
가족 공유 가족 식별자, 구성원과 역할, 가입·수정 시점, 초대 코드의 해시와 만료 시각, 동기화 버전. 가족 접근 권한과 기록 동기화에 사용합니다.
기기 내 진단 일별 기능 사용 횟수, 저장·동기화 상태. 기기에 저장되며 사용자가 진단 내용을 내보내거나 문의에 첨부할 수 있습니다.
문의 발신 이메일, 사용자가 보낸 문의 및 첨부 자료. 문의 답변과 문제 확인에 사용합니다.

현재 버전에는 광고·분석·충돌 수집 SDK가 포함되어 있지 않습니다. 향후 처리 항목이나 목적이 달라지면 방침과 필요한 안내 절차를 먼저 정비합니다.

2. 기기 저장과 가족 공유

  • 게스트: 입력한 식단과 식사 기록은 앱의 기기 저장소에 저장됩니다. 로그인 기능 준비를 위해 외부 서비스가 초기화될 수 있으므로 모든 네트워크 통신이 없다는 의미는 아닙니다.
  • 가족 연결: 가족과 연결한 기록은 Firebase 서버에도 저장되어 같은 가족의 구성원이 볼 수 있습니다. 로그인만으로 다른 가족이나 일반 사용자에게 공개되지는 않습니다.
  • 오프라인: 변경 사항을 기기에 보관하고 연결 복구 후 동기화합니다. 다른 기기 변경과 충돌하면 앱의 선택 안내를 확인해야 합니다.
  • 내보내기: 사용자가 내보낸 식단 파일에는 아이 별명과 기록이 들어갑니다. 사용자가 별도로 저장·전달한 파일은 앱 탈퇴로 회수되지 않습니다.

가족 구성원에게는 공유 식단과 아이별 기록이 표시됩니다. 함께 볼 사람만 초대해 주세요. 구성원 권한이 회수된 기기라도 오프라인인 동안에는 즉시 원격 삭제할 수 없습니다.

3. 외부 서비스와 국외 처리

인증과 클라우드 기능에 Google Firebase를, 선택한 로그인 방식에 따라 카카오·Google·Apple을 이용합니다. 소셜 로그인 제공자는 자체 방침에 따라 계정 인증을 처리하며, 앱이 처리하는 정보의 범위는 로그인 방식과 제공 정보에 따라 다릅니다.

  • Firebase Authentication: 회원 인증 정보는 미국에서 처리됩니다.
  • Cloud Firestore·Cloud Functions: 현재 개발 환경의 가족 기록 저장소와 서버 함수는 서울 리전(asia-northeast3)입니다. 모든 인증·운영 정보가 국내에만 저장된다는 뜻은 아닙니다.
  • 카카오: 서버가 일시적으로 전달받은 로그인 토큰으로 계정 및 앱을 검증하고 Firebase 인증과 연결합니다.
  • 웹사이트: 정적 호스팅에 GitHub Pages를 사용합니다. GitHub는 보안 목적으로 방문자의 IP 주소 등 접속 정보를 처리할 수 있습니다. 이 페이지에는 별도 광고·방문 분석 스크립트를 넣지 않았습니다.

수탁자 법인명·업무 범위, 국외 이전 대상·국가·시점·방법·보유기간·연락처·법적 근거 및 거부 방법은 운영 계약을 확인해 정식 방침에 확정해야 합니다. 위 내용만으로 법정 국외 이전 고지나 동의 절차가 완료된 것은 아닙니다.

외부 서비스 설명: Firebase 개인정보 보호 · GitHub 개인정보처리방침

4. 보유 기간과 삭제

  • 기기 기록: 앱 내 기록 삭제 또는 앱 데이터 제거 시 삭제됩니다. 연결된 가족의 로그아웃·계정 삭제 시 앱은 해당 로컬 기록도 정리합니다. 기기 백업이나 내보낸 파일은 별도로 관리해야 합니다.
  • 회원 정보: 계정 삭제 시 앱 서버의 회원 연결 정보와 Firebase 인증 계정 삭제를 요청합니다. 소셜 서비스 계정 자체는 삭제하지 않습니다.
  • 공유 가족: 다른 구성원이 남아 있으면 공동 식단·기록은 유지됩니다. 마지막 구성원이 가족을 나가면 해당 가족·식단·구성원·초대 데이터가 서버에서 삭제됩니다.
  • 초대: 초대 코드는 24시간 후 사용할 수 없게 됩니다. 만료 즉시 저장 데이터가 자동 파기되는 것은 아니며, 코드 사용·새 코드 생성 시 정리 또는 가족 삭제 과정에서 삭제됩니다.
  • 서비스 측 보존: Firebase는 인증 IP 로그를 수 주간, 삭제 요청된 인증 데이터의 운영·백업 사본을 최대 180일 내 제거한다고 안내합니다. 앱의 삭제 완료가 모든 외부 백업의 즉시 소멸을 뜻하지 않습니다.

문의 메일, 서버 운영 로그 및 백업의 구체적 보유기간·파기 절차는 공개 전 확정 항목입니다. 법령상 보존 의무가 적용되면 그 항목·근거·기간을 정식 방침에 구체적으로 안내합니다.

5. 열람·수정·삭제와 문의

앱에서 식단과 아이 정보를 확인·수정·삭제할 수 있습니다. 회원 탈퇴는 ‘우리 가족’의 계정 삭제 기능을 이용하세요. 앱에 접근할 수 없는 경우에도 웹의 계정 삭제 요청 안내를 통해 문의할 수 있습니다.

개인정보 열람·정정·삭제·처리정지 등의 요청은 hello@twinlabs.studio로 보내 주세요. 계정 소유자 및 보호자 권한을 확인하는 과정이 필요할 수 있습니다. 비밀번호나 인증 코드를 보내지 마세요.

6. 보호 조치와 아동 정보

서버의 인증 및 가족 구성원 권한으로 접근을 제한합니다. 로그인 토큰 등 비밀정보를 공개 페이지나 문의에 포함하지 않도록 안내합니다. 기기 잠금과 내보낸 파일의 보관은 사용 기기 환경에 맞게 관리해 주세요.

보호자가 입력하는 아이 정보도 개인정보가 될 수 있습니다. 만 14세 미만 아동 정보에 대한 법정대리인 동의 및 확인 절차의 적용 여부와 구현을 공개 전에 검토합니다. 별명 사용만으로 이러한 의무가 없어지는 것은 아닙니다.

7. 공개 전 확인 사항

  • 운영 환경의 위탁 계약과 국외 이전 고지·동의 요건 확정
